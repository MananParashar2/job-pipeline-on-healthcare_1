# 🏥 Healthcare Data Pipeline using Databricks & PySpark

A data engineering project that implements an end-to-end healthcare data pipeline using **Databricks**, **Apache Spark (PySpark)**, and a **Medallion Architecture (Silver → Gold)**. The project cleans raw healthcare order data, performs business aggregations, and presents key insights through an interactive dashboard.

---

## 📌 Project Overview

This project demonstrates a modern data engineering workflow by processing healthcare order data into analytics-ready datasets.

The pipeline consists of three stages:

- **Task 1:** Data Cleaning & Transformation (Silver Layer)
- **Task 2:** Business Aggregations (Gold Layer)
- **Task 3:** Interactive Dashboard & Visualization

The objective is to transform raw transactional healthcare data into meaningful business insights that can support decision-making.

## 📊 Pipeline Workflow

### Task 1 – Data Cleaning

- Reads raw healthcare order data
- Converts `order_date` into proper date format
- Calculates:

```
total_value = quantity × price
```

- Stores cleaned data in:

```
silver_healthcare_orders
```

---

### Task 2 – Business Aggregation

Reads data from the Silver layer and creates Gold tables.

Generated outputs:

### Revenue by Service Category

```
gold_healthcare_category_sales
```

### Daily Revenue

```
gold_healthcare_daily_sales
```

These tables are optimized for analytics and reporting.

---

### Task 3 – Dashboard

Builds an interactive dashboard that displays:

- Total Revenue KPI
- Top Performing Service Category
- Revenue by Service Category (Bar Chart)
- Daily Revenue Trend (Line Chart)
